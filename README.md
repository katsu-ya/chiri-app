# にっぽん ちり クイズ

小学生向けの日本の地理クイズアプリです。
`index.html` の1ファイルだけで動きます（HTML / CSS / JavaScript）。インストールやサーバーは不要で、インターネットにつながっていなくても使えます。

## つかいかた

1. `index.html` をブラウザ（Chrome・Safari・Edge など）で開きます。
2. 「① ジャンル」を選びます。
   - 都道府県 ／ 県庁所在地 ／ 地方区分 ／ 山・川・平野・湖 ／ 名所・名物 ／ ぜんぶ まぜる
3. 「② ちほう」を選びます。
   - 全国 ／ 北海道・東北 ／ 関東 ／ 中部 ／ 近畿 ／ 中国・四国 ／ 九州・沖縄
   - 地方を選ぶと、地図がその地方を大きく映します（ほかの地方はうすい色になります）。
4. 「スタート！」を押すと、10問がランダムに出ます。
5. 答えると、正解と短い解説が出て、自動で次の問題へ進みます。
   - 正解：2秒後　／　不正解：4秒後
   - 「つぎへ ▶」を押すと、待たずに進めます。
6. 10問終わると、点数と全問のふりかえり（⭕ / ❌）が出ます。

パソコンでは、キーボードの 1〜4 で選択肢を選び、Enter キーで次へ進めます。

## 問題の形

| 形 | 内容 |
|---|---|
| 光っている県を答える | 地図で光っている都道府県の名前を4択で答える（小さい県はまわりに輪が出ます） |
| 地図をタップ | 都道府県名を見て、地図の正しい場所をタップする |
| 4択 | 「○○県の県庁所在地は？」「日本一長い川は？」など |
| ○× | 「○○県は 近畿地方に ある。○か ×か？」など |

- 答えたあと、地図の上で **正解の都道府県は緑**、**まちがえて選んだ都道府県は赤** になります。県庁所在地の問題では、県庁所在地の場所に赤い点が出ます。
- 漢字にはすべてふりがながついています。

### 小さい都道府県のタップ

「全国」の地図で東京都・神奈川県・大阪府などの小さい都道府県のあたりをタップすると、まずその地方が大きく映ります。そこで正しい都道府県をタップして答えます（「◀ ぜんたい に もどる」で全国に戻れます）。
北海道・沖縄県や、画面の上で十分大きい都道府県は、1回のタップで答えになります。
少し外れた海の上をタップしても、すぐ近くの都道府県を選んだことになります。

## ふくしゅう（まちがえた問題）

- まちがえた問題はブラウザに保存され、はじめの画面の「📕 ふくしゅう」から解き直せます（最大10問ずつ）。
- ふくしゅうで正解すると、その問題はリストから消えます。
- 結果画面の「まちがえた ○もん を もういちど」で、その回にまちがえた問題だけをすぐ解き直せます。

## おぼえた ちず

はじめの画面の「🗾 おぼえた ちず」で、都道府県ごとの覚えぐあいを色で見られます。

| 色 | 意味 |
|---|---|
| 緑「おぼえた！」 | その都道府県の問題に 3回連続 で正解 |
| 黄「もうすこし」 | 1〜2回連続で正解 |
| 赤「にがて」 | 最後に答えた問題がまちがい |
| 白 | まだ出ていない |

- その都道府県が答えになる問題（都道府県・県庁所在地・地方区分、1つの県だけにある名所・名物など）を数えます。
- 地図の都道府県をタップすると、地方・県庁所在地・正解／まちがいの回数が見られます。

## カレンダー（がんばりの きろく）

はじめの画面に、けいさんアプリ（`../math-app/index.html`）と同じ仕組み・見た目のカレンダーがあります。

- 問題に答えるたびに、その日の問題数が1つ増えます（途中で「やめる」を押しても、答えた分は数えます）。
- 1日に **10問以上** で赤い「○」、**20問以上** で「花丸」がつきます。
- 記録は **けいさんアプリとは別々** に数えます（保存する名前がちがいます）。

記録・ふくしゅう・おぼえた地図はブラウザ（localStorage）に保存されるので、閉じても消えません。

- 記録はブラウザ・端末ごとに別々です（パソコンとスマホの記録は合算されません）。
- ブラウザの履歴やサイトデータを消すと、記録も消えます。

| 保存の名前 | 中身 |
|---|---|
| `chiri-quiz-records` | カレンダーの記録（日付ごとの問題数） |
| `chiri-quiz-wrong` | まちがえた問題 |
| `chiri-quiz-mastery` | 都道府県ごとの正解・まちがい・連続正解の回数 |

## 画面

- パソコンでは、左に大きな地図、右に問題・選択肢・解説が並び、スクロールせずに1画面に収まります。
- スマホでは、問題 → 地図 → 選択肢 → 解説 の順に縦に並び、1画面に収まります。地図をタップする問題では選択肢がなくなり、そのぶん地図が大きくなります。

## 設定の変え方

`index.html` の中を書きかえると変更できます。

| やりたいこと | 書きかえる場所 |
|---|---|
| 1回の問題数を変える | `const TOTAL = 10;` |
| 正解のあと次へ進むまでの時間 | `const AUTO_NEXT_OK_MS = 2000;`（1000 = 1秒） |
| 不正解のあと次へ進むまでの時間 | `const AUTO_NEXT_NG_MS = 4000;` |
| 「おぼえた」になる連続正解の回数 | `const LEARNED_STREAK = 3;` |
| 山・川・平野・湖の問題を増やす | `const NATURE = [...]` |
| 名所・名物の問題を増やす | `const FAMOUS = [...]` |

問題の文では、`{漢字|かんじ}` と書くとふりがなつきで表示されます。

## 地図データ

都道府県の形は、国土地理院「地球地図日本」の行政界データ（[dataofjapan/land](https://github.com/dataofjapan/land) で TopoJSON に変換されたもの）を、形がくずれない程度に点を減らして SVG にしたものです。県庁所在地の位置も同じリポジトリのデータを使っています。

- 沖縄県と奄美群島（鹿児島県）は、九州の左上の枠の中に少し大きくして表示しています。
- 小笠原諸島・大東諸島と、ごく小さな島は省いています。
- 地球地図日本の利用条件にしたがい、出典を画面と README に書いています（営利目的で使う場合は、国土地理院への利用報告が必要です）。
